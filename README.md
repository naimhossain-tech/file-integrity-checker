# File Integrity Checker

A simple Python tool to calculate the SHA-256 hash of a file.

## Features

- Calculates SHA-256 hash
- Helps verify file integrity
- Simple command-line interface
- Built with Python

## Requirements

- Python 3

## Usage

Run the script:

python checker.py sample.txt

Replace sample.txt with the path to the file you want to check.

## Example

The tool prints the SHA-256 hash of the selected file.

## Purpose

This project is for learning Python and basic cybersecurity concepts.
